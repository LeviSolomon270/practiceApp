Kotlin vs TypeScript
Kotlin is a statically -typed, cross -platform, multi -purpose 
programming language with type inference.
TypeScript is a strongly typed programming language that 
extends JavaScript. This means that the app won’t compile if 
you have type(variable) errors.
---
PAGE 11
Why TypeScript over JavaScript?
When building large apps , relying on standard error checking 
in JavaScript can lead to unexpected issues.
With TypeScript’s strong typing, it is harder to write bad code.
